# Context - Jewelry AI App (Private)

## What This Is
This project is a private, Android-first Flutter app for a jewelry business. It generates photorealistic marketing images of models wearing the exact jewelry from a reference product photo. The app is not public, not consumer-facing, and not a general AI image tool.

## Why This Exists
Direct prompt-driven AI tools are inconsistent for non-technical users. This app removes free-form prompting and replaces it with a guided, structured flow. It encodes best-practice prompting once and reuses it to improve fidelity and consistency.

## The User Experience
The user follows a short, guided flow:
1. Upload one or more jewelry reference photos.
2. Select jewelry type.
3. Choose model profile (gender, age, skin tone).
4. Choose setting and composition.
5. Generate and view results, then share or reuse settings from history.

The user never writes a prompt.

## Core Principles
- Fidelity over creativity: Preserve shape, stones, metal tone, proportions.
- Structure beats flexibility: Limited options with strong defaults.
- Private and focused: Single business, single workflow.
- Simple UI, strong logic: Clean UI with strict prompt constraints.

## What This App Is Not
- Not a general-purpose AI image generator.
- Not a jewelry design tool.
- Not a public SaaS product.
- Not an inventory or catalog system.

## Success Definition
The app is successful if:
- A user can generate a usable image in under one minute.
- Jewelry remains visually faithful to the reference.
- Results are consistent across repeated use.
